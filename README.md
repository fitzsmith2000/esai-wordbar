# esai单词

原生 macOS 状态栏背词应用，沿用 esai 的花朵与绿色视觉。打开面板直接查看释义、语境例句；可在词书自带释义、柯林斯、ECDICT 英汉与英英之间切换。按「忘了 / 模糊 / 认识」安排复习。

**词书**决定要背哪些词，负责出词与学习进度；**释义**决定面板显示哪套解释，不改变背词清单。

## 构建与使用

公开测试版：[下载 0.9.1](https://github.com/fitzsmith2000/esai-wordbar/releases/tag/v0.9.1)，选择 `esai-wordbar-0.9.1-public.dmg`，把“esai单词”拖到“应用程序”，然后打开它。也可下载 `.pkg` 按安装向导操作。公开测试版不包含 Collins 或 ECDICT 数据库；可在「设置 → 释义」中自行下载。应用只出现在状态栏，不显示 Dock 图标；点状态栏单词打开面板。

测试版目前尚未取得 Apple Developer ID 公证。如果 macOS 阻止首次打开，请先尝试打开一次，再按 [Apple 官方步骤](https://support.apple.com/en-us/102445) 在「系统设置 → 隐私与安全性」中确认“仍要打开”。

从源码构建：需要 Apple Silicon Mac、macOS 13+、Swift 命令行工具和 Rust Cargo。运行 `zsh build.sh`；运行 `zsh package.sh` 制作公开测试版安装包，若本机已有个人 Collins 数据库，还会额外制作仅供个人使用的安装包。安装包已包含 MDX 解析器，安装软件的用户不需要安装 Rust。

- 默认 `⌥ F10` 下一词、`⌥ ⇧ F10` 上一词、按住 `⌥ ⇧ F9` 临时显示中文；揭晓释义后可用 `⌥⌘1 / 2 / 3` 选择“忘了 / 模糊 / 认识”。六个组合都可在「设置 → 快捷键」录制修改。
- 「设置 → 外观」可调状态栏字号，并切换界面模式、背景与强调色。
- 「设置 → 词书」把已安装词书和下载入口分开；在「我的词书」中选择或导入，在「下载词书」中下载热门考试词书或 FreeMdict 精选。点击学习面板顶部的当前词书也能直达。
- 「设置 → 释义」可选择词书自带释义、柯林斯或 ECDICT。未安装时点击下载，之后离线查询；释义库不会改变背词进度。
- 点开状态栏单词即可直接输入英文查词；匹配结果及释义在同一面板显示，清空查询或点击「返回背词」回到原来的单词。
- 「设置 → 通用」可手动检查更新，或选择自动检查、下载并在正常退出时安装。首次使用需要先手动安装支持更新的版本。
- CSV/TSV 表头至少需要 `word,meaning`，可添加 `phonetic,example,example_zh`；参见 `sample-book.csv`。
- 柯林斯和 ECDICT 从本地词库查询；无需 API 密钥。只有用户点击下载时才联网。没有词库时，词书自带释义照常显示。

学习进度与自定义词书保存在 `~/Library/Application Support/esai-wordbar/`，设置保存在系统偏好。词条内容和复习进度不上传。

下载内容由用户在应用内按需获取；应用验证文件后在本机转换为背诵词书或释义库。下载站若更新了文件，应用会提示文件版本不匹配；内置的雅思场景词表与词书自带释义仍可离线使用。

## 内容与许可

内置 7,298 条词汇来自 [Word Atlas](https://github.com/designfuchen/word-atlas) 的 `data/word-atlas.json`，以 **CC BY 4.0** 授权，署名 **Word Atlas contributors**。本应用将其按 CEFR 和话题重新筛选成四个学习词表，未改动单条词条。原数据由 AI 生成并经自动校验，未逐条人工审校；这些不是雅思官方词表。

状态栏以外的花朵图标、原生弹窗宿主、玻璃分段控件与部分外观控件来自 [esai](https://github.com/fitzsmith2000/esai)，原项目采用 **AGPL-3.0**。本项目源代码同样按 AGPL-3.0 发布；完整条款见 `LICENSE`，组件署名见 `THIRD_PARTY_NOTICES.md`。

## 本地柯林斯词库

公开安装包、自动更新 ZIP 和源码仓库都不包含 Collins 或 ECDICT 词条。可在「设置 → 释义」点击下载；应用会在本机转换并保存到 `~/Library/Application Support/esai-wordbar/dictionaries/`。旧的个人安装版若内含柯林斯词库，启动时会复制到这个位置，以便后续更新继续使用。

若自行构建安装包，可用 `tools/convert_collins.py` 转换自己持有的 MDX：先安装 Python 依赖 `readmdict`、`python-lzo`、`beautifulsoup4`，再运行 `python3 tools/convert_collins.py /path/to/Collins.mdx`。`python-lzo` 需要系统 LZO 开发库（Homebrew：`brew install lzo`）。转换脚本基于 [readmdict](https://github.com/ffreemt/readmdict) 的读取接口。

# esai单词 0.8.1 公开测试版

适用于 macOS 13 及以上的 Apple Silicon Mac。初次安装请下载 `esai-wordbar-0.8.1-public.dmg`，打开后把“esai单词”拖入“应用程序”；也可使用 `.pkg` 安装向导。

这一版提供状态栏背词、四本内置雅思场景词书、FreeMdict 词书下载、自定义 CSV/TSV 词书、可录制快捷键、低调评分按钮和本机签名更新。词书现在是设置的直接入口，点击面板顶部的当前词书也可直达。

公开安装包不包含 Collins 词条；没有个人词库时，词书自带释义仍可使用。自动更新 ZIP 同样不含 Collins 数据。安装包使用 ad hoc 代码签名，尚未经过 Apple Developer ID 公证；若 macOS 阻止首次打开，请参照 [Apple 官方说明](https://support.apple.com/en-us/102445)。

测试反馈请提交到本仓库 Issues。安装包的 SHA-256 校验值见 `SHA256SUMS-public.txt`。
